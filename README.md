## 🚀 Cara Menjalankan Project (Modul 1)
1. Masuk ke direktori modul:
   ```bash
   cd praktikum-react-modul1
   ```
2. Install dependensi:
   ```bash
   npm install
   ```
3. Jalankan server development:
   ```bash
   npm run dev
   ```
4. Buka di browser: `http://localhost:5173/`
